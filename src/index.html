Help & Guide

How Kairo works, start to finish. Click a section to expand it.

Getting started

Kairo listens to whoever's preaching, matches what's said against the Bible in real time, and puts the right verse on screen automatically — the same way a slide operator would, without someone driving it live.

  1. Open Settings → Audio and pick the microphone (or audio-routing device, e.g. BlackHole) capturing the preacher.
  2. Open Settings → Outputs and turn on at least one destination — usually External Display for the projector/screen.
  3. Set the spoken language under Settings → Language if it isn't English.
  4. Press Start in the Bible tab. Live Status switches from Idle to Listening, and the Live Transcript Log starts filling in as words are heard.

Everything else — playlists, slides, songs, themes — can be prepared before or during the service; detection runs independently in the background the whole time.

Live scripture detection

A verse can reach the screen two ways, and both are meant to just work without anyone pressing a button:

  • A citation is spoken — "turn to Romans chapter 8, verse 28" — sends that verse immediately.
  • Scripture is read aloud, cited or not — Kairo matches the actual words against the Bible text itself, so a passage read without ever naming chapter/verse still reaches the screen.

A confident match auto-sends straight to Live Status/the output. A weaker or ambiguous match shows up under Possible Matches instead — click one there to send it manually. This two-tier behavior is deliberate: a wrong verse on screen is worse than a missed one, so anything Kairo isn't confident about waits for a human glance rather than guessing.

Reading forward through a passage (verse 1, then 2, then 3…) is tracked automatically, including a spoken "range" citation ("verses 1 to 9") — the display advances verse-by-verse as the reading continues, without needing each one re-cited.

Building a service

The left sidebar is your run-of-show — a playlist of items in the order they'll go out. Each top tab is a different kind of content to add:

  • Bible — search and add specific verses directly; also where Live Status, the transcript log, and Possible Matches live during a service.
  • Slides — your own slide decks (announcements, sermon notes, anything not scripture).
  • Songs — hymns and lyrics, with section labels (Verse/Chorus/Bridge) and line-by-line/section navigation.
  • Timer — countdowns for service segments, sent to the output's own timer layer independently of whatever slide/verse is showing.
  • Media — images and video, sent to their own independent media layer (doesn't interrupt or get interrupted by slides/verses).

Use + New in the sidebar to create additional named playlists (e.g. one per service) — Default is just the one that's there from the start.

Click any slide in an item to send it live; the currently-live slide is highlighted. Right-click a slide for more options (duplicate, delete, split, etc.).

Importing content

Bring in existing material instead of rebuilding it by hand, from either File → Import or the + button on a playlist item:

  • Import file… — text, Word, PowerPoint, and ProPresenter files (.pro6/.pro7/.probundle/.proplaylist).
  • Paste from clipboard — pasted lyrics/text, split into slides automatically.

ProPresenter files are handled specially. Kairo auto-detects them and preserves the file's own design exactly as authored — fonts, colors, positions, images, layer structure — instead of reformatting it into a Kairo theme. The Add dialog shows a notice confirming this rather than asking you to pick a theme, since none is needed. A playlist file with several presentations imports all of them at once, each keeping its own original layout.

A plain text/Word import instead asks how to split it into slides (by paragraph, or a fixed number of lines each) and which theme to render it with, since there's no original design to preserve.

Theme Studio & looks

Theme Studio (the Looks tab) is where a slide's actual design lives — background, text position/font/color, animations. A theme applies to every slide in an item that doesn't have its own override.

A ProPresenter-imported slide is the one exception: it carries its own preserved layout directly (see Importing above), independent of whichever theme is assigned to the rest of the item — editing it in Full-Scale Edit adjusts that one slide's own layers, not a shared theme.

The Multi-Language theme is a special split layout — the verse's own language on one side, a translated version on the other (see Multi-Language below).

Sending to outputs

Settings → Outputs lists every destination on the left; click one to see and edit its settings on the right. Use + Add Output (top right) to add a Display/Projector, an NDI output, or a Syphon output — each new one can be renamed and given its own theme. The switch in each output's header (list row or detail panel) turns that destination on or off; a dot next to it shows whether it's actually connected/broadcasting.

  • External Display — a real window sent to a projector/screen/monitor. Enable at least one; it's what most services actually need. If it doesn't come back after restarting the app, reselect it here — this should happen automatically on launch, but a manual reselect always forces it.
  • NDI — broadcasts over the network to any NDI-aware app (OBS, vMix, ProPresenter, etc.), on any platform. Requires the free NDI Tools runtime installed on this machine first (ndi.video/tools) — Kairo doesn't bundle it. If the toggle won't turn on, the output's status line will say why (usually "NDI runtime not found").
  • Syphon (macOS) / Spout (Windows) — same idea as NDI but same-machine only, and bundled with Kairo (nothing extra to install). Any Syphon- or Spout-aware app on the same computer (OBS, ProPresenter, Resolume, etc.) can pick it up directly. The Add Output menu only offers the one that matches the computer Kairo is running on.
  • OBS — a lightweight built-in text push into a single OBS Text Source, for a quick lower-third without adding an NDI/Syphon source in OBS. For full parity (images, video, timer, not just verse text), add an NDI or Syphon source inside OBS pointed at Kairo instead — that's the recommended setup.
  • ProPresenter — there's no separate Kairo-side integration for it. Add Kairo as an NDI or Syphon source directly inside ProPresenter, the same way you would in OBS.

Each NDI/Syphon output also has its own configurable resolution and network/source name, editable any time under its detail panel.

Multi-language

Under Settings → Language: Spoken language is what the preacher is actually speaking (drives transcription). Scripture language is what a matched verse displays in — install additional Scripture packs to add languages, downloaded once for offline use.

Slide Translation Models are separate — they translate ordinary (non-scripture) slide/sermon text for the Multi-Language split theme, using a small bundled local model with no setup, API key, or internet connection required once downloaded.

Keyboard shortcuts

See the Shortcuts section (just above this one) for the full customizable list — click Change next to any action, then press the new key combo.

Troubleshooting
  • Nothing is being detected — confirm the right microphone/audio device is selected under Settings → Audio and that Live Status shows Listening, not Idle.
  • A verse is correct but never appears live — check Possible Matches; a lower-confidence detection waits there for a manual click rather than auto-sending.
  • The output window is blank or on the wrong screen — reselect it under Settings → Outputs → External Display.
  • An NDI output won't turn on — install the free NDI Tools runtime (ndi.video/tools) and try the toggle again; Kairo doesn't bundle it. The output's own status line shows the exact reason when it fails.
  • An imported file lost its look — only ProPresenter files preserve their own design automatically; a plain text/Word import always uses a Kairo theme instead, by design.

Playlist

The Bible tab's left panel is your service's running order — songs, scripture readings, slides, all in one list, in the order you'll actually go through them. Click + New to add an item, drag to reorder, and click any item to load it. Whatever's live is always highlighted so you never lose your place mid-service.

Slides

Need something besides scripture on screen — an announcement, a welcome slide, song lyrics? The Slides tab is a full text/background editor. Build a slide, pick a theme for it, and send it live with one click — it uses the exact same output pipeline as everything else, so it shows up wherever you've configured Bible content to appear.

Timer

The Timer tab tracks your service's segments — Preservice, Worship, Sermon, whatever you name them — each with its own countdown. Only one runs at a time, and it displays live on any output you've enabled the Timer layer for, so your team always knows exactly how much time is left.

Themes

Theme Studio controls how everything looks — fonts, colors, backgrounds, animations. Build as many themes as you want, then assign a different one to each output (a subtle look for the stage confidence monitor, a bold one for the main screen) under Settings → Outputs.

Outputs

Send your service to a projector or monitor (Display), a network feed (NDI), a same-Mac compositor (Syphon), or OBS. Add as many as you need under Settings → Outputs — each one gets its own theme and its own choice of which layers (Bible/Slide/Media/Timer) it actually shows.

You're all set

That's the whole app. Everything you just saw is always reachable from the tabs at the top and from Settings — nothing here was a one-time setup step. Jump in, and revisit this tour anytime from Settings → Help.
